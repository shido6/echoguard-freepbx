# EchoGuard connector for FreePBX

Connect a FreePBX system to [EchoGuard](https://echoguard.ca) so Greg can take
snapshots, run a small set of bounded diagnostics, and issue reload commands
when you ask — **outbound-only, no inbound ports, no free-form shell**.

**Guides:** [Admin guide](docs/ADMIN-GUIDE.md) (install, secure, troubleshoot)
· [User guide](docs/USER-GUIDE.md) (connect once, then ask for a look)

```
FreePBX box ──(outbound HTTPS poll)──▶ app.echoguard.ca ──▶ your EchoGuard console
```

## What v0.1 can do

| Op | What it does |
| --- | --- |
| `snapshot` | FreePBX/Asterisk versions, active channel count, uptime, disk headroom |
| `diagnose` | SIP registration counts (registered vs rejected/unregistered), disk pressure, plain-language hints |
| `reload` | A standard `fwconsole reload` |
| `module_reload` | Reload one allowlisted module: `core`, `pjsip`, `sipsettings`, `ivr`, `timeconditions`, `ringgroups`, `queues`, `miscapps`, `customappctx`, `confirm`, `findmefollow` |

## What v0.1 deliberately cannot do

- No free-form shell or command strings — the agent executes named ops only.
- No dialplan/destination/routing/schema edits (roadmap — will ship behind server-side schema validation, never free-form SQL).
- No audio, no recordings, no CDR bulk export.
- The agent opens **no listening ports**; it polls outbound over HTTPS.

## Install

1. In your EchoGuard console: **Phone systems → Add FreePBX** — copy the one-line setup command it gives you.
2. On the FreePBX server:

```bash
tar xzf echoguard-freepbx-0.1.0.tar.gz && cd echoguard-freepbx
sudo ./install.sh --endpoint https://app.echoguard.ca --node <id> --key <key>
```

3. The installer writes `/etc/echoguard/agent.conf` (mode 600), enables
   `echoguard-agent.service`, and runs a self-test. Status appears in the
   console within ~15 seconds.

GUI note: drop `module.xml` + `page.echoguard.php` into
`admin/modules/echoguard/` if you want a FreePBX GUI page for the same config —
the agent works with or without the GUI module.

## Security model

- **Node key** is generated by EchoGuard, shown **once**, stored on the box as
  a 600-mode config file; only a SHA-256 hash is kept server-side.
- Every agent request presents `X-Echoguard-Node: <id>:<key>`; comparison is
  constant-time. Revoking the node in the console rejects the key on the next
  poll (401) and the agent stops.
- **The same op allowlist is enforced twice**: cloud-side when the command is
  created, and agent-side before execution. `module_reload` accepts a fixed
  module name list on both sides.
- Everything the agent runs goes through `echoguard_ops.php`, which shells out
  only to fixed commands (`asterisk -rx '...'`, `fwconsole reload ...` with an
  escaped, allowlisted module name, `df`).

## Files

| Path on the box | Purpose |
| --- | --- |
| `/usr/local/bin/echoguard-agent` | The agent (`run`, `status`, `self-test`) |
| `/usr/local/lib/echoguard/echoguard_ops.php` | Bounded op executor |
| `/etc/echoguard/agent.conf` | Endpoint + node id + key (600) |
| `/var/lib/echoguard/last-status.json` | Last check-in, for the GUI page |
| `systemd: echoguard-agent.service` | Always-on poller, auto-restart |

## Uninstall

```bash
sudo ./uninstall.sh
```

Then revoke the node in the EchoGuard console.

## Built on the shoulders of giants

The SIP-signaling mirroring on our roadmap rides **HEP**, the open capture
protocol maintained by the [sipcapture project](https://sipcapture.org/) — the
same open plumbing behind [HOMER](https://github.com/sipcapture/homer) (the
100% open-source capture system) and [hepic](https://hepic.tel) (QXIP's
carrier-grade stack), with the full ecosystem catalogued in
[awesome-hep](https://github.com/sipcapture/awesome-hep). We didn't invent the
standard, we don't ship their code, and we never brand anything of ours as
"Hepic" or "HOMER" — those names belong to their projects. Naming them here
simply points at the standard this lane speaks; no affiliation, sponsorship, or
endorsement is implied. FreePBX and Asterisk are their respective projects'
trademarks — this is an independent, community connector.
